# Original assets

The four vector doodle characters are original drawings implemented in `src/Character.tsx`: bean, ghost, star and blob. They take broad inspiration from playful scribble art, with their own silhouettes, expressions, accessories and linework.

The bundled `assets/audio/table-party.wav` is an original four-bar, 120-BPM synthesized loop, generated by `python scripts/make_music.py`. The melody, bass, kick, hats and clap use mathematical oscillators and seeded noise. It contains no third-party recordings or samples. Music and code share the repository licence.

## v0.3 effects and rendering assets

`python scripts/make_fx.py` regenerates six short original synthesized WAV cues and the original `assets/animations/reward.json` Lottie burst. The Lottie JSON is used by the native renderer only; web rewards use bounded Reanimated particles and a trophy. All these original assets share the repository licence. Materials such as felt grain, building windows, metallic wheel sectors and food-column textures are procedural SVG geometry/gradients. There is no downloaded texture pack or third-party sprite atlas.
